# OlmaxPdf 

OlmaxPdf.ImageSharp is a .NET 8.0, .NET 10 library that bridges the two libraries. It allows you to leverage PDFium to handle layout and extraction, and then output pages or extract assets directly into native ImageSharp Image objects.
Supports Linux-x64, OSX-x64, Win-x64, Win-x86.

### Usage

- [Nuget Package](https://www.nuget.org/packages/OlmaxPdf.ImageSharp).

### Build Requirements
- .NET 8.0, .NET .10
